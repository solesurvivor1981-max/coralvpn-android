# CoralVPN Client — спека Android-приложения «одна кнопка»

Версия 1.0 (2026-09-20) · Статус: черновик для команды разработки · Владелец: Alexander Solntsev

---

## 1. Суть продукта

Минимальное Android-приложение для подключения к CoralVPN: **открыть → одна большая кнопка Connect/Disconnect**. Без выбора протоколов, без ручных конфигов, без списка серверов в MVP (пикер — во второй версии).

- Один протокол: **Hysteria2** (весь прод CoralVPN — hy2-only)
- Ядро: **sing-box (libbox)** — официальные Go-биндинги для Android
- Конфиг клиент получает **готовым** с sub-server (`?fmt=singbox`) — парсить подписки не нужно
- Дистрибуция: **APK на GitHub Releases** (вне Google Play, никто не удалит). Кнопка скачивания уже есть в боте

## 2. Референсы и базы

## 3. Пользовательские сценарии (MVP)

### 3.1 Первый запуск
1. Пользователь в боте нажимает «📲 Скачать приложение (APK)» → GitHub releases → установка
2. Приложение предлагает вставить ссылку подписки (или перехватывает deeplink, см. §5)
3. Приложение скачивает `?fmt=singbox` JSON → сохраняет → показывает **одну большую кнопку Connect**
4. Android просит разрешение VpnService → согласие → подключено

### 3.2 Повторный запуск
- Открыл приложение → кнопка → подключено за 1–2 сек
- Автообновление подписки: при подключении и по интервалу из HTTP-заголовка `Profile-Update-Interval` (сейчас 1 ч)

### 3.3 Статус на главном экране
- Connected / Disconnected (зелёная/серая кнопка)
- Текущий сервер (имя из selector), флаг-эмодзи
- Истёкшая подписка → баннер «Продлить в боте» (deeplink в @Coral_VPN_bot) + блокировка Connect
- Expire + остаток трафика — из заголовка `Subscription-Userinfo` (upload/download/total/expire)

### 3.4 Не в MVP (backlog)
Пикер серверов (уже поддержан конфигом — selector CORALVPN), kill-switch настройка, автозапуск при загрузке, тёмная тема, виджет, iOS-версия.

## 4. Интеграция с sub-server (контракт)

### 4.1 Получение конфига
```
GET https://sub-ru.ai-boost.tech/sub/{sub_id}?fmt=singbox
→ 200 application/json — валидный sing-box config (проходит sing-box check, ≥1.12, ориентирован на 1.14)
→ 404 — подписка не активна (показать «продлить в боте»)
```
Fallback-хост, если sub-ru недоступен: `https://miniapp.ai-boost.tech/sub/{sub_id}?fmt=singbox` (зеркало).

### 4.2 Что в конфиге (сингл-источник правды — сервер)
- `outbounds`: selector **CORALVPN** (`.outbounds` — список серверов с человеческими именами вида «🇷🇺 Универсальный (автоматический)», `.default` — сервер по умолчанию) + 9 hy2-аутбаундов + direct/block
- `inbounds`: tun (в приложении tun создаётся сам VpnService; поле может игнорироваться)
- DNS: DoH 1.1.1.1 через туннель, локальные/приватные IP — мимо VPN, DNS перехват (hijack-dns)

### 4.3 Заголовки (считывать при каждом обновлении)
| Заголовок | Смысл |
|---|---|
| `Profile-Title` | Имя профиля («AI Boost Tech VPN ☀️») |
| `Profile-Update-Interval` | Часы между автообновлениями |
| `Subscription-Userinfo` | `upload=…; download=…; total=…; expire=<unix>` — трафик и срок |
| `Support-Url` | Ссылка на саппорт-бота |

### 4.4 Что клиент делает с конфигом
1. Скачал JSON → **отдал в libbox как есть** (без мутаций)
2. Для Connect: запускает конфиг; сервер на стороне клиента = selector CORALVPN
3. Смена сервера (backlog): `selector.select = <tag>` через libbox API — пикер уже заложен в конфиг

## 5. Deeplink

- Схема: `coralvpn://add?url=<urlencoded подписка-URL>` (плюс приём plain `https://sub-ru.ai-boost.tech/sub/{id}` intent)
- Бот будет выдавать кнопку «Открыть в CoralVPN» с этим deeplink (добавим после MVP)
- Обработать в AndroidManifest (singleTask, intent-filter на схему coralvpn)

## 6. Технические требования

- **minSdk 24** (Android 7.0), targetSdk — актуальный (34+)
- **VpnService** + подготовка permission flow при первом Connect
- **libbox**: golang 1.22+, gonum; сборка через gomobile; CI на GitHub Actions (сборка APK на tag)
- Необходимые разрешения: `INTERNET`, `FOREGROUND_SERVICE`, `POST_NOTIFICATIONS` (13+), `RECEIVE_BOOT_COMPLETED` (backlog)
- Стабильность: foreground notification с кнопкой Disconnect и статусом
- Обновление конфига: только когда приложение не подключено ИЛИ атомарная замена с перезапуском ядра
- Хранение: sub_url в EncryptedSharedPreferences; кэш конфига во внутреннем хранилище
- Безопасность: HTTPS-only к sub-server; не логировать sub_id/UUID в системный лог

## 7. Проверка качества (acceptance)

1. Свежая установка → вставка ссылки → Connect → интернет через VPN (проверка: 2ip/whoer показывает выход сервера CoralVPN)
2. Повторный Connect/Disconnect ×10 — без вылетов и утечек (strict_route в конфиге)
3. Подписка истекла → баннер + Connect заблокирован
4. Полёт самолёта / потеря сети → соединение восстанавливается автоматически
5. Обновление подписки не роняет активную сессию
6. APK ставится на Android 7–15 (вкл. ТВ-приставки без Google Play)

## 8. Этапы и оценка

| Этап | Содержимое | Оценка |
|---|---|---|
| 0. Каркас | Форк SFA или скелет + libbox, сборка CI, APK-артефакт | 2–3 дня |
| 1. MVP | Импорт ссылки, скачивание конфига, кнопка, статус, expire/трафик | 1–1.5 нед |
| 2. Дистрибуция | GitHub releases, semver, кнопка в боте, in-app проверка обновлений | 2–3 дня |
| 3. Полировка | Пикер серверов, автозапуск, иконка/брендинг, ТВ | 1–2 нед |

Итого MVP: **~2 недели** одного Android-разработчика. Полный продукт с полировкой: ~1 месяц.
