# CoralVPN Client — описание продукта (для команды разработки)

Дата: 2026-09-20 · Спонсор: Alexander Solntsev · Контекст: сервис CoralVPN (@Coral_VPN_bot, ~750 юзеров, hy2-only инфраструктура)

## Проблема

Сейчас клиентское приложение у нас — сторонний Happ (прокси-клиент). Это создаёт три проблемы:

1. **Дистрибуция.** Happ Lite удалён из App Store (сент. 2026), полный Happ доступен в RU-регионе только через смену региона Apple ID. Google Play тоже может «попросить на выход» в любой момент. Пользователи теряются на этапе установки.
2. **Бренд и конверсия.** Пользователь ставит «чужое» приложение, видит чужой бренд, мы не контролируем UX первого запуска — самую критичную точку онбординга.
3. **Сложность для пользователя.** Универсальные клиенты перегружены опциями (протоколы, конфиги, роутинг). Нашему пользователю нужно одно: «нажал — работает».

## Решение

Свой Android-клиент **CoralVPN Client** — «одно приложение, одна кнопка»:

- Открыл → вставил ссылку из бота (или кликнул по ней — deeplink) → нажал Connect → интернет пошёл через VPN. Всё.
- Ядро — **sing-box** (проверенный open-source движок, GPL; на нём же работают SFA/Karing).
- Конфиг клиент получает **готовым с нашего сервера**: парсеры подписок, логика выбора серверов и обхода блокировок живут на нашей стороне, где их легко чинить без выпуска новых версий приложения.
- Дистрибуция — **APK напрямую с GitHub** (установочный файл не может быть «удалён из стора»). Кнопка в боте уже есть.
- Работает и на ТВ-приставках / устройствах без Google Play.

## Почему это дёшево

- Весь прод CoralVPN работает на **одном протоколе Hysteria2** — клиенту не нужна поддержка 20 протоколов.
- Сервер уже отдаёт **готовый sing-box конфиг** (`?fmt=singbox`, в проде, протестирован живым E2E). Клиент: скачал JSON → отдал libbox → подключил. Вся «умная» часть уже сделана.
- Есть эталонный open-source клиент (SFA) — его можно взять за каркас и выпилить лишнее.

## Целевой пользователь и метрика успеха

- Наш действующий пользователь CoralVPN (Android — большинство платящих).
- **Метрика успеха:** доля новых пользователей, успешно подключившихся с первого раза ≤ 5 минут; снижение тикетов «не могу установить/настроить».
- Ниша: приложение **дополняет** Happ (для тех, у кого с ним проблемы), а не мгновенно заменяет.

## Ключевые сценарии (MVP)

1. **Подключение с первого раза:** установка APK → deeplink/вставка ссылки → разрешение VPN → Connect.
2. **Одна кнопка:** Connect/Disconnect + статус + имя текущего сервера + срок подписки и остаток трафика.
3. **Автообновление подписки** по интервалу от сервера.
4. **Истёкшая подписка:** баннер «Продлить в боте» с deeplink в @Coral_VPN_bot.

Что осознанно НЕ в MVP: пикер серверов (заложен в конфиг, добавим сразу после), iOS-версия, автозапуск при загрузке.

## Этапы и сроки

| Этап | Результат | Срок |
|---|---|---|
| Каркас + CI | APK собирается автоматически на GitHub Actions | 2–3 дня |
| MVP | Все сценарии из спеки §3, внутреннее тестирование | ~2 недели |
| Публикация | GitHub releases + кнопка в боте + проверка обновлений in-app | +2–3 дня |
| Полировка | Пикер серверов, брендинг, ТВ | +1–2 недели |

Команда: 1 Android-разработчик (Kotlin) + 0.5 DevOps (уже закрыто — серверная часть готова) + дизайн иконки/заставки (разово).

## Риски

| Риск | Митигация |
|---|---|
| Android запрещает sideload у части пользователей | Инструкция в боте + альтернатива Happ остаётся; Play-версию рассмотрим позже (политика Google к VPN-клиентам) |
| sing-box API меняется между версиями | Конфиг генерирует сервер под конкретную версию ядра; клиент шлёт версию ядра в User-Agent — сервер может отдавать совместимый JSON |
| GPL (форк SFA) | Публикуем исходники — для нас это не проблема, бренд выигрывает от открытости |
| Подделка APK (фишинг) | Публикуем checksums + подпись релизов, кнопка в боте ведёт только на официальный релиз |

## Что уже готово со стороны сервера

- `GET https://sub-ru.ai-boost.tech/sub/{sub_id}?fmt=singbox` — валидный sing-box JSON (selector CORALVPN с именованными серверами, DNS через туннель, приватные сети мимо VPN)
- Заголовки `Profile-Title` / `Subscription-Userinfo` (срок, трафик) / `Support-Url` / `Profile-Update-Interval`
- E2E-мониторинг всех 9 серверов каждые 5 минут (метрики + Grafana + алерты)
- Смена/добавление серверов — правкой только на сервере, без релиза приложения
